## 🆘 Need Help?

**If setup fails:**
1. Check SETUP_GUIDE.md section "Configuration"
2. Check HANDOFF.md section "Support & Debugging"
3. Run: `npm install` again
4. Try: `rm -rf node_modules && npm install`

**If imports fail:**
1. Check tsconfig.json has correct paths
2. Verify component filenames match imports
3. Restart dev server: Ctrl+C then `npm run dev`

**If styles don't work:**
1. Check tailwind.config.ts is updated
2. Check globals.css has @tailwind directives
3. Rebuild: `npm run dev`
